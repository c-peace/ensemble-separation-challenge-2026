# Sample data

[샘플 ZIP 다운로드 · 6.02 MB](https://raw.githubusercontent.com/c-peace/ensemble-separation-challenge-2026/main/samples/sample-dataset.zip)

GitHub 저장소에 포함된 실제 파일입니다. 전체 약 20.65 GB 자료는 [기존 서버](https://www.chopss.kr/ensemble/downloads/dataset.zip)에서 받습니다.

SynthSOD·URMP 각각 5초의 혼합음과 모든 정답 악기 파일을 포함합니다. WAV 9개, 44,100 Hz · mono · float32. 각 트랙의 구간·길이는 동일합니다.

청취·입출력 형식 확인용입니다. 전체 평가용 데이터셋의 대체물이 아니며 학습이나 공식 순위 계산에 사용하지 않습니다. ZIP 안의 README.md, SOURCES.md, manifest.json에서 출처, 라이선스, 가공 내역, 해시를 확인하세요.
