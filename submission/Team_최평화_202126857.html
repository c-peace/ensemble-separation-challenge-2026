Ensemble Benchmark

합주에서, 악기별 소리로.

4·5파트 합주를 악기 종류별 오디오로 분리하는 대회입니다.

어떻게 평가하나요?
분리한 음원을 정답 음원과 비교합니다. SDR로 순위를 정하고, SIR·SAR도 함께 표시합니다.
어떻게 시작하나요?
제공 데이터와 학습·평가 노트북으로 시작하세요. 모델은 자유롭게 개선할 수 있으며, 추가 데이터는 사용 규칙을 따라야 합니다.

소용량 샘플 받기 · 6.02 MB ↗ · 혼합음과 정답을 먼저 확인해 보세요.

참가·평가 페이지에서 가공된 학습·검증 데이터 ZIP을 내려받으세요. 선정된 학습곡 365개 중 전체 무음인 sod_507·sod_968을 제외한 363곡을 제공합니다. 공개 검증 데이터 30개(SynthSOD 24 · URMP 6)는 평가용 데이터셋이며, 혼합음과 정답 stem을 함께 제공합니다. evaluate.ipynb로 이 데이터의 성능을 재현·비교할 수 있습니다. 별도 test 음원은 포함하지 않습니다. 곡 목록과 학습 제외 목록은 코드 키트에 들어 있습니다.

추가 데이터 사용 규칙

  • 허용: 대회에서 제공한 학습 데이터와 그 증강 자료. 추가 데이터는 SynthSOD·URMP 이외의 데이터만 허용하며, 출처와 사용 조건을 확인해야 합니다.
  • 학습 금지: 제공 학습 데이터 이외의 SynthSOD·URMP 원본 및 파생 자료. 검증·평가 보호 작품의 오디오·정답 stem·악보·MIDI와 재합성·변형 자료. 자기지도학습과 테스트 시 적응도 포함합니다.
  • 검증은 설정 선택에만: 검증 점수로 모델·설정을 선택할 수 있습니다. 평가 정답으로 반복 튜닝하지 마세요.
  • 사전학습 모델: 학습 내역을 확인할 수 있고 위 금지 데이터를 사용하지 않은 모델만 허용합니다.
  • 사용 내역 제출: 추가 데이터·가중치의 이름, 버전, 출처, 라이선스와 중복 검토 결과를 기록하세요.
학습 제외 범위 확인

SynthSOD 원본 train 중 보호 작품 관련 43개를 제외했습니다. 같은 작품의 악장·편곡·렌더·부분 혼합은 같은 구간으로 묶습니다. 미선정된 원본 evaluation/test도 학습에 사용할 수 없습니다.

목록의 train.allowed_sod_ids는 허용 ID, train.quarantined는 잠정 제외 목록, protected_synthsod_records는 보호 작품 목록입니다. 제목 기반 중복 검토가 반영되어 있으며 최종 검수 시 변경될 수 있습니다.

1. 베이스라인으로 시작하기

SynthSOD X-UMX 기반 대회용 베이스라인입니다. 허용된 학습곡으로 새로 학습하며, 악기군별 4개 모델과 전체 출력에 대한 Wiener 보정 1회를 사용합니다.

샘플 데이터 다운로드ZIP · 6.02 MB · GitHubSynthSOD·URMP 각 5초 + 정답 악기 음원전체 다운로드ZIP · 20.65 GB코드 + 학습·검증 데이터코드 다운로드ZIP · 72.5 KB학습·평가 노트북 + 코드 키트데이터 다운로드ZIP · 20.65 GB학습·검증 음원

샘플은 청취·파일 형식 확인용입니다. GitHub에서 내려받으며, 전체 데이터 ZIP을 대체하지 않습니다. 학습·공식 성능 평가는 서버의 전체 데이터로 실행하세요.

전체 ZIP을 풀거나 코드 ZIP을 풀고 데이터 ZIP을 추가해, 네 파일을 같은 폴더에 준비하세요. Colab에서는 /content에 두고 학습 → 평가 노트북 순서로 실행합니다. 먼저 두 노트북의 SMOKE=False를 True로 바꿔 연결을 확인한 뒤, 전체 실행 시 다시 False로 설정하세요.

데이터 ZIP에는 가공된 학습·검증 음원이 들어 있으며 노트북이 자동으로 압축을 풉니다. 전체 묶음은 PC에서 먼저 풀어 네 파일만 Colab에 올리세요. 데이터 ZIP과 해제 데이터에 약 41.3 GB가 필요하고, 모델·결과 저장 공간도 별도로 확보하세요. 평가 노트북은 학습 노트북이 저장한 모델을 불러옵니다. 검증 실험 점수는 리더보드에서 확인할 수 있습니다. 학습 가중치는 별도로 배포하지 않습니다.

50:50 합산과 작품별 집계는 대회 규칙입니다. 현재 리더보드는 배포된 공개 검증 데이터 30개로 평가합니다. 별도 test 데이터의 결과는 표시하지 않습니다.

공통 채점 코드는 키트와 평가 노트북에 포함되어 있습니다. URMP에 없는 3개 범주를 0점으로 처리하지 않습니다.

정답 오디오의 처리 기준
  • SynthSOD: Tree 음원의 채널 평균을 사용하며 잔향을 유지합니다. Close Mic와 혼용하지 않습니다.
  • URMP: 개별 파트를 48k→44.1k로 동일하게 polyphase resampling(147/160)합니다.
  • 선택 파트를 합쳐 혼합음을 만들고, 같은 출력 범주의 파트를 정답 하나로 합칩니다.
  • 혼합음 peak 0.75에 맞춘 하나의 gain을 혼합음과 모든 정답에 적용합니다. 개별 stem 정규화는 하지 않습니다.
  • 각 target의 유효 1초 프레임이 5개 이상인 장면만 배포합니다.
